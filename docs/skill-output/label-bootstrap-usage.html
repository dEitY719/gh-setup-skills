label-bootstrap 사용 결과

한 줄 요약 — 라벨 SSOT 정의(references/gh-labels.md)를 받아 대상 repo 의 GitHub 라벨 집합을 생성합니다.

입력 라벨 SSOT (.md)
스킬 /gh-setup:label-bootstrap
산출물 repo 라벨 12종
1

실행한 명령

범용 형식

usage 
/gh-setup:label-bootstrap [--repo <owner/repo>] [--dry-run] [--prune]

이번 예시에 실제로 쓴 명령 (드라이런 — 변경 API 호출 0회)

bash 
$ bash skills/label-bootstrap/lib/label-bootstrap.sh --repo dEitY719/gh-setup-skills --dry-run
2

입력

  • skills/label-bootstrap/references/gh-labels.md
    10개 분류 라벨, 3개 별칭 매핑, 2개 파이프라인 상태 라벨의 단일 정의처
  • 대상 repo: dEitY719/gh-setup-skills
    라벨이 GitHub 기본값뿐인 새 repo
3
