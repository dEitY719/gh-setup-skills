gh-setup-skills

스킬 설명서와 실행 기록

새 repo 를 세울 때 한 번만 돌리는 네 개의 스킬입니다. 각 스킬마다 무엇을 만들어 내는지 정리한 설명서와, 실제로 한 번 실행해 그 출력을 그대로 옮긴 사용 결과가 한 쌍으로 있습니다.

plugin: gh-setup 스킬 4종 문서 8건

스킬

label-bootstrap 라벨

repo 의 라벨을 10개 SSOT 라벨과 2개 파이프라인 상태 라벨로 강제 동기화합니다. 별칭 3개는 삭제가 아니라 이름 변경이라 기존 이슈가 라벨을 잃지 않고, --prune 없이는 아무것도 지우지 않습니다.

설명서 사용 결과
kanban-bootstrap 보드

Projects v2 보드를 만들고 repo 를 연결한 뒤 Status 필드를 6컬럼 워크플로로 교체합니다. 라벨 단계는 형제 스킬에 위임하고, 대상은 언제나 origin 하나입니다.

설명서 사용 결과
docs-bootstrap 문서 골격

8개 리프로 이루어진 kind-split docs/ 트리와 정책 README 를 만듭니다. 네트워크도 gh 도 필요 없고, 기본이 dry-run 이라 --apply 를 명시해야 파일이 생깁니다.

설명서 사용 결과
add-ai-metrics 백필

자동 캡처 이전에 만들어진 Issue/PR 본문에 메트릭 푸터를 소급해 붙입니다. 이미 푸터가 있는 카드는 건너뛰므로 같은 명령을 다시 던져도 안전하고, 그 성질이 곧 재개 메커니즘입니다.

설명서 사용 결과

각 페이지는 docs/skill-guides/ 와 docs/skill-output/ 아래의 마크다운 원본에서 생성됩니다. 사용 결과 문서에 적힌 명령과 출력은 실제 실행 기록이며, 라이브 repo 를 바꾸는 스킬은 dry-run 으로 잡았습니다.
